# Country data

Bundled IPtoASN country ranges are redistributed from sapics/ip-location-db.
Source: https://github.com/sapics/ip-location-db
Original provider: https://iptoasn.com/
License: Open Data Commons Public Domain Dedication and License (PDDL) 1.0.
License text: https://opendatacommons.org/licenses/pddl/1-0/
Source URLs, SHA-256 checksums and retrieval time: extension/data/provenance.json.
Country data describes IP allocation / network country, not verified physical server location.
The extension never updates this database over the network. Maintainers update it before releases.
